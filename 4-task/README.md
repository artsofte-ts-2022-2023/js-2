Реализуйте функцию `multiplyPropertyValue`, которая в качестве входных параметров принимает объект, тип поля и количество его "умножений".
Тип поля может быть либо `string`, `number`, либо `boolean`. В остальных случаях нужно генерировать исключение.
Значение для умножения - только число, большее 0.
Функция должна умножать значения объекта указанного типа указанное количество раз, в случае с boolean - инвертировать его значение (1 раз).
В данном задании объект, переданный функции, может содержать другие объекты, которые также должны быть проверены согласно условию задачи.
